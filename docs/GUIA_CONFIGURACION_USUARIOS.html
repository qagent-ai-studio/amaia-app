📱 Guía de Configuración

AMAIA - Botón de Emergencia BLE
Configuración de dispositivos de usuario

⚠️ IMPORTANTE: Lee antes de configurar

Esta guía es para el personal de Mistatas que instalará la app Amaia en los dispositivos de los beneficiarios. Sigue cada paso cuidadosamente para garantizar que el botón de emergencia BLE funcione correctamente, especialmente en dispositivos Samsung.

📋 Requisitos del Dispositivo

Marca Versión Android Requisitos Especiales Estado
Samsung A06 Android 15 One UI 8.0 o superior ✅ Compatible
Samsung (otros modelos) Android 14+ One UI 8.0 o superior ✅ Compatible
Samsung (modelos antiguos) Android 14 One UI 7.x o inferior ⚠️ Requiere actualización
Huawei / Otros Android 9+ Sin requisitos especiales ✅ Compatible

Pasos de Configuración

1
Verificar Versión del Sistema (Solo Samsung)

¿Por qué? Los dispositivos Samsung requieren One UI 8.0 para que el botón de emergencia funcione completamente.

  • Abre Configuración en el dispositivo
  • Ve a Acerca del teléfono
  • Busca Información de software
  • Verifica la Versión de One UI

✅ Si dice "One UI 8.0" o superior:

Continúa con el Paso 2

❌ Si dice "One UI 7.x" o inferior:

Debes actualizar el dispositivo:

  • Ve a Configuración → Actualización de software
  • Toca Descargar e instalar
  • Espera a que se descargue e instale
  • Reinicia el dispositivo
  • Verifica nuevamente la versión
2
Instalar App Amaia
  • Descarga el archivo APK de Amaia
  • Abre el archivo APK en el dispositivo
  • Si aparece advertencia de "Origen desconocido", permite la instalación
  • Toca Instalar
  • Espera a que termine la instalación
  • Toca Abrir cuando finalice
3
Configurar Permisos Básicos

Al abrir la app por primera vez, solicitará varios permisos. Otorga TODOS:

📍 Ubicación
  • Selecciona "Permitir todo el tiempo" o "Permitir siempre"
  • NO selecciones "Solo mientras se usa la app"
📱 SMS y Llamadas
  • Toca "Permitir" cuando pida permiso de SMS
  • Toca "Permitir" cuando pida permiso de Llamadas
🔔 Notificaciones
  • Toca "Permitir" cuando pida permiso de Notificaciones
📡 Bluetooth
  • Toca "Permitir" cuando pida permiso de Bluetooth
4
Activar "Mostrar sobre otras apps" (CRÍTICO para Samsung)

¿Por qué? Este permiso es OBLIGATORIO para que el botón de emergencia pueda hacer llamadas automáticas cuando la app está cerrada en dispositivos Samsung.

⚠️ MUY IMPORTANTE

Sin este permiso, el botón NO hará llamadas automáticas en Samsung. Solo enviará SMS.

  • Ve a Configuración → Aplicaciones
  • Busca y selecciona Amaia
  • Toca el menú ⋮ (tres puntos verticales) en la esquina superior derecha
  • Selecciona "Aplicaciones especiales" o "Acceso especial"
  • Busca la opción "Mostrar sobre otras apps" o "Aparecer encima"
  • Busca Amaia en la lista
  • Activa el interruptor para permitir

✅ Verificación exitosa:

Debe aparecer como: Amaia: Permitido ✅

📸 Captura de pantalla: Configuración → Aplicaciones → Amaia → ⋮ → Aplicaciones especiales → Mostrar sobre otras apps → Amaia: PERMITIDO
5
Desactivar Optimización de Batería (RECOMENDADO)

¿Por qué? Garantiza que el servicio BLE se mantenga activo 24/7 sin interrupciones.

Método 1 (Recomendado):

  • Ve a Configuración → Aplicaciones
  • Selecciona Amaia
  • Toca Batería
  • Selecciona "Sin restricciones"

Método 2 (Alternativo):

  • Ve a Configuración → Batería y cuidado del dispositivo
  • Toca Batería
  • Toca el menú ⋮ → Ajustes
  • Busca "Aplicaciones no monitoreadas"
  • Toca el + (más) y agrega Amaia

✅ Verificación exitosa:

En Configuración → Aplicaciones → Amaia → Batería debe decir: "Sin restricciones"

6
Verificar Notificaciones

¿Por qué? Para que el usuario reciba confirmación visual cuando se envía el SMS de emergencia.

  • Ve a Configuración → Aplicaciones → Amaia
  • Toca Notificaciones
  • Verifica que "Mostrar notificaciones" esté ACTIVADO ✅
  • Busca el canal "MK Button Emergencias" o "MK Button Service"
  • Toca sobre el canal
  • Verifica que esté configurado como "Alertas" o "Hacer sonido y mostrar"
  • NO debe estar en "Silencio"
7
Configurar Botón BLE en la App

Ahora configura el botón MK Button dentro de la app Amaia:

  • Abre la app Amaia
  • Ve a la sección de configuración del botón BLE
  • Enciende el botón MK Button físico (presiona 3 segundos)
  • Toca "Buscar dispositivos" o "Conectar"
  • Selecciona el botón de la lista (debe aparecer como "MK Button" o similar)
  • Ingresa la contraseña si se solicita (por defecto: Moko4321)
  • Configura el número de emergencia (+56994633411 o el número asignado)
  • Selecciona el tipo de clic (simple, doble o largo)
  • Selecciona la acción: "Enviar SMS y llamar"

✅ Conexión exitosa:

Debe aparecer una notificación permanente que diga: "MK Button Activo - Conectado"

8
Probar el Botón de Emergencia

Prueba 1: Con app abierta

  • Con la app abierta, presiona el botón físico BLE
  • Verifica que:
    • ✅ El teléfono vibra (3 pulsos)
    • ✅ Se envía un SMS al número configurado
    • ✅ Se inicia una llamada automática

⚠️ IMPORTANTE: Prueba crítica

Prueba 2: Con app cerrada (LA MÁS IMPORTANTE)

  • Cierra completamente la app Amaia:
    • Desliza desde abajo (botón de apps recientes)
    • Desliza Amaia hacia arriba para cerrarla
  • Verifica que la notificación "MK Button Activo" siga visible
  • Presiona el botón físico BLE
  • Verifica que:
    • ✅ El teléfono vibra inmediatamente (3 pulsos)
    • ✅ Se envía SMS con ubicación GPS al número configurado
    • ✅ Se inicia llamada automática ⭐ (crítico en Samsung)

✅ Prueba exitosa:

Si todas las acciones funcionan con la app cerrada, el botón está configurado correctamente.

❌ Si la llamada NO se inicia con app cerrada:

Verifica:

  • Paso 4: Permiso "Mostrar sobre otras apps" debe estar activado
  • Paso 1: Dispositivo Samsung debe tener One UI 8.0 o superior
  • Reinicia la app y vuelve a probar

🔧 Solución de Problemas Comunes

Problema 1: La llamada NO se inicia con app cerrada

Síntomas: El SMS sí se envía, vibra correctamente, pero NO se abre el marcador telefónico.

Solución:

  • Verifica que el permiso "Mostrar sobre otras apps" esté activado (Paso 4)
  • Verifica que el dispositivo Samsung tenga One UI 8.0 o superior (Paso 1)
  • Reinicia completamente la app y vuelve a conectar el botón
  • Si el problema persiste, reinicia el dispositivo

Problema 2: El botón deja de funcionar después de horas

Síntomas: El botón funciona al principio, pero después de horas deja de responder.

Solución:

  • Verifica que la batería esté configurada como "Sin restricciones" (Paso 5)
  • Ve a Configuración → Batería → Aplicaciones no utilizadas
  • Asegúrate de que Amaia NO esté en la lista de apps pausadas
  • Si está pausada, elimínala de esa lista

Problema 3: No aparece la opción "Mostrar sobre otras apps"

Síntomas: No encuentras esta opción en el menú de Amaia.

Solución:

  • Verifica que el dispositivo tenga One UI 8.0 (Paso 1)
  • Si tiene versión anterior, actualiza el sistema
  • Reinicia el dispositivo después de actualizar
  • Intenta nuevamente acceder al permiso
