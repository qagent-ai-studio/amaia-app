⚠️ DISPOSITIVOS SAMSUNG: Verificar que tengan One UI 8.0 o superior. Sin esta versión, el botón NO hará llamadas automáticas. Actualizar desde: Configuración → Actualización de software.
1️⃣ INSTALACIÓN DE LA APP
Instalar APK de Amaia
Abrir archivo APK → Permitir instalación de origen desconocido → Instalar → Abrir
2️⃣ OTORGAR PERMISOS BÁSICOS
Ubicación: "Permitir siempre" o "Permitir todo el tiempo"
⚠️ NO seleccionar "Solo mientras se usa la app"
SMS: Permitir
Llamadas: Permitir
Notificaciones: Permitir
Bluetooth: Permitir
3️⃣ CONFIGURACIÓN AVANZADA (CRÍTICO)
🔴 MOSTRAR SOBRE OTRAS APPS (OBLIGATORIO para Samsung)
Configuración → Aplicaciones → Amaia → Menú ⋮ → Aplicaciones especiales → "Mostrar sobre otras apps" → Buscar Amaia → ACTIVAR
Sin esto, NO hará llamadas automáticas en Samsung
Optimización de batería: "Sin restricciones"
Configuración → Aplicaciones → Amaia → Batería → Sin restricciones
Notificaciones: Verificar canales activos
Configuración → Aplicaciones → Amaia → Notificaciones → Todo activado (NO en silencio)
4️⃣ CONECTAR BOTÓN BLE
Encender botón MK Button (presionar 3 segundos)
Conectar en la app → Buscar → Seleccionar botón
Contraseña por defecto: Moko4321
Configurar número de emergencia: +56994633411
Seleccionar tipo de clic: ___________________
(simple / doble / largo)
Seleccionar acción: "Enviar SMS y llamar"
Verificar notificación: "MK Button Activo - Conectado"

5️⃣ PRUEBAS OBLIGATORIAS

PRUEBA 1: Con app abierta
Presionar botón BLE → Verificar: ✓ Vibración ✓ SMS enviado ✓ Llamada iniciada
🔴 PRUEBA 2: Con app COMPLETAMENTE CERRADA (MÁS IMPORTANTE)
1. Cerrar app (deslizar hacia arriba desde apps recientes)
2. Verificar que notificación "MK Button Activo" siga visible
3. Presionar botón BLE
4. Verificar: ✓ Vibración ✓ SMS con GPS ✓ Llamada automática
Si la llamada NO se inicia, verificar Paso 3: "Mostrar sobre otras apps"
